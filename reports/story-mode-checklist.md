# Story mode: the things that still need checking

These are the problems reported during testing and the checks for the next build. An unchecked box means it still needs verification. This page is not a list of fixes already shipped.

## Let me see the map

- [ ] Keep Build and Attack in the expandable circular controls.
- [ ] Center icons and labels; remove overlapping controls on landscape phone screens.
- [ ] Replace long warning paragraphs with small icons and resource changes.
- [ ] Keep the plus and minus zoom buttons.
- [ ] Put Exit in the pause menu and never start a new game paused.
- [ ] Keep event choices brief, useful and out of the way once answered.

## People should actually do their jobs

- [ ] Automatically assign an available worker team without interrupting a busy team.
- [ ] Finish gathering trips, respect carrying limits and return supplies home.
- [ ] Make food gathering and farming support the settlement instead of letting it collapse with no useful response.
- [ ] Let faster scouts explore toward a goal, use supplies and encounter danger.
- [ ] Reveal unowned and enemy land through scouting without conquering it.
- [ ] Make army deployment and movement clear, with progress toward the chosen target.
- [ ] Keep cleared trees cleared and discovered resources visible.
- [ ] Scatter forests and other objects naturally instead of lining them up.

## The less glamorous part

- [ ] Save and resume resources, discovered land, buildings and active jobs correctly.
- [ ] Test leaving and reopening the mobile app, not just refreshing a browser.
- [ ] Mute and unmute repeatedly without losing audio.
- [ ] Stop menu music when story music starts. One soundtrack at a time, please.
- [ ] Measure performance while revealing new land.
- [ ] Test marketplace content compatibility with older game versions before changing the live service.
